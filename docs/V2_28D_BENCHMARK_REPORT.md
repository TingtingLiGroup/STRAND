**关键结论（非常有启发性）**：
1. **跨尺度崩溃被 100% 根治**：坐标缩小 `15x` 到真实微米级（~22 µm）后，原版 `v1_raw_17d` 的 Macro F1 暴跌至 **0.4482**（`Foci` 召回率 `0.4%`、`Protrusion` 召回率 `8.4%`）；而 `v2_full_28d` 和 `v2_full_28d_sparse_aug` 在 `1x` 与 `1/15x` 下输出**逐小数位完全一致（`0.9778` / `0.9696`）**。
2. **揭示了一个极其重要的交互效应**：如果只加 `feat_log1p_n_spots` 和尺度归一特征，但训练集只喂 SimFISH 原始高丰度点云（中位数 67 点），树模型会学到「只要点数少或二阶矩偏小就全判 `Foci`」，导致 `v2_full_28d` 在 `6–10` 点稀疏端反而掉到 `0.3138`（`Random` F1=0.00，全被误判为 `Foci`）。
3. **稀疏下采样增强 + 28 维特征实现全场景双赢**：一旦在训练集中加入 `6–20` 点下采样副本（`v2_full_28d_sparse_aug`），模型学会利用 `feat_log1p_n_spots` 与 `csr_z_*` 联合校准稀疏阈值：
   - 原分布高丰度 Macro F1 达到 **0.9696**（高于原版 `0.9550`）；
   - `11–20` 点区间 Macro F1 从 `0.8013` 跃升至 **0.8843**（`mlogloss` 减半）；
   - `6–10` 点极稀疏区间 Macro F1 从 `0.4789` 暴涨 **+30.0 个百分点至 0.7789**（`Foci` F1 从 `0.344 -> 0.819`，`Random` F1 从 `0.072 -> 0.551`）。

**真实数据核心验证发现**：
1. **完美印证实验 3 的稀疏机制**：在 `#10_1`（中位数 9 个点）和 `#33_1`（中位数 12 个点）这两个真实 micron 数据集上：
   - 旧模型 `v1_raw_17d` 因微米尺度导致 `Foci`（0.00% / 0.01%）和 `Radial`（0.06% / 0.06%）彻底死区；
   - 未做稀疏增强的 `v2_full_28d` 则把低丰度基因大面积误判成 `Foci`（61.8% / 38.4%）；
   - **`v2_full_28d_sparse_aug` 一步到位解决了两边的问题**：既激活了真实的 `Foci`（2.80% / 1.33%）与 `Radial`（9.89% / 1.47%），又没有发生 `Foci` 爆炸，整体 8 类比例非常符合生物学常识。
2. **阳性对照锚点基因大幅改善（以 `#33_1 MERFISH U2OS` 500 细胞为例）**：
   - **`MALAT1`（经典核内 lncRNA）**：旧模型 `v1_raw_17d` 仅 **58.8% `Nuclear`**（另有 40.0% 漏判成 `Random`）；`v2_full_28d_sparse_aug` 提升至 **92.4% `Nuclear`**（与 `#5 pixel` 下的 94.4% 高度吻合）！
   - **`FBN2` & `COL5A1`（经典内质网/核周分泌蛋白 mRNA）**：旧模型 `v1_raw_17d` 主导模式全错判为 **`Random`**（41.6% / 47.3%，`Nuclear edge` 仅 34.2% / 24.7%）；`v2_full_28d_sparse_aug` 准确翻转为 **`Nuclear edge` 主导（63.1% / 59.4%）**，与 `#5 pixel` 下的 `Nuclear edge` 主导（51.6% / 62.2%）完全一致！
   - **`Carmn`（`#10_1` 小鼠脑核内 lncRNA）**：从 `100% Random` 修正为 `100% Nuclear`；胶质/髓鞘胞质基因 `Mbp`（59.7% `Cytoplasmic` + 25.3% `Cell edge`）、`Cst3`（70.7% `Cytoplasmic`）保持高置信胞质/突起定位。
3. **暴露了一个只有真实数据才会出现的物理差异（直接指向第二步主动学习的必要性）**：
   - 为什么 `#5 MERFISH U2OS`（Moffitt 2016 早期多 z 层直接合并 2D 的数据）无论是旧模型（65.5%）还是新模型（82.0%）都给出了极高的 `Foci`？
   - 实测 `#5` 的单细胞点云发现：同一个基因（如 `SPTBN1`，单细胞 836 个点）有 25% 的点一阶最近邻距离 `< 0.14 px`（约 `15 nm`，远小于光学衍射极限），这是 **3D 多 z 层同位置重复检出投影到 2D 平面产生的物理重影/双计点（z-stack duplicate spots）**，导致其 `csr_z_nn_clustering` 中位数高达 `9.68`（而现代去重后的 `#33_1 U2OS` 仅为 `0.51`）。
   - 这恰恰说明：**纯 SimFISH 模拟器无法预知不同实验管线的光学重影/去卷积伪影**。现在我们已经拥有了尺度不变、稀疏校准的 **`v2_full_28d_sparse_aug` 最强 Round 0 基座**，下一步通过 **Agent 视觉盲标 + 主动学习微调**（以及可选的亚衍射极限重复点合并预处理），就能把这类平台特异性伪影也彻底驯服。
